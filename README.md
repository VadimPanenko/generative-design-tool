# Генеративный сервис для дизайнеров

> AI-сервис для автоматической генерации графических материалов в корпоративном стиле

## 🎯 Описание проекта

Интеллектуальная система генерации изображений для создания 3D-иконок и графических материалов, соответствующих корпоративному стилю и бренд-буку.

### Ключевые возможности

- **Генерация по текстовому описанию** - создание 3D-иконок за 1-4 минуты вместо 2-3 часов ручной работы
- **Автоматический корпоративный стиль** - система автоматически применяет цвета и стилистику из бренд-бука
- **Поддержка русского языка** - простое текстовое описание без специальных навыков
- **Быстрые итерации** - возможность редактирования и улучшения результатов

### Целевая аудитория

- Дизайнеры интерфейсов (UI/UX)
- Графические дизайнеры
- Презентационные дизайнеры
- Арт-директора
- Маркетинговые команды


## 🏗️ Архитектура

**Основные компоненты:**
- **FLUX.1-dev** - генерация изображений
- **DeepSeek-R1 / Qwen2.5** - обогащение промптов и перевод
- **FastAPI** - backend сервис
- **Веб-интерфейс** - пользовательский интерфейс

Подробная архитектура описана в [дизайн-документе](docs/ml_system_design_doc.md).
