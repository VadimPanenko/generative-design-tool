# FLUX Image Generation

## Описание

Этот проект предназначен для генерации изображений с помощью различных режимов (модов) на базе моделей FLUX.1-dev и связанных инструментов. Основной скрипт — `main.py`, который позволяет гибко управлять процессом генерации через параметры командной строки.

## Основные режимы генерации (`--mode`)

- **basic / basic_4bit** — базовая генерация изображения по текстовому описанию (prompt). Версия 4bit использует более экономичное по памяти представление модели (качество почти идентично полновесной модели).
- **img2img / img2img_4bit** — преобразование входного изображения по заданному описанию (image-to-image).
- **fill / fill_4bit** — дорисовка/инпейтинг: генерация недостающих частей изображения по маске. Белый цвет маски - область, которая будет изменена, чёрный - область, которая будет оставлена без изменений.
- **depth / depth_4bit** — генерация с учётом карты глубины (depth map) для управления структурой сцены. Использует специальные эмбеддинги и карту глубины, получаемую через `get_depth` из utils.py. Сейчас на сервере есть только depth_4bit.
- **redux / redux_4bit** — режим, использующий дополнительные эмбеддинги референсного изображения и текста для более точного соответствия референсу (использует SigLIP и ReduxImageEncoder).
- **flux_upscale / flux_upscale_4bit** — увеличение разрешения изображения с помощью ControlNet. Использует функцию `prepare_image_for_flux_upscale` из utils.py.
- **remove_bg** — удаление фона на изображении (сегментация, используется AutoModelForImageSegmentation и функция `remove_bg` из utils.py).

## Основные параметры скрипта

- `--prompt` — основной текстовый запрос для генерации.
- `--prompt_2` — дополнительный промпт для T5. Если задать prompt_2, то prompt пойдёт в CLIP (поэтому имеет смысл делать prompt подходящим для CLIP - перечень слов, фраз, а для T5 писать полноценные предложения). Если не задать prompt_2, то prompt пойдёт и в CLIP и в T5. 
- `--negative_prompt`, `--negative_prompt_2` — негативные промпты (что не должно быть на изображении). negative_prompt_2 действует аналогично prompt_2 - идёт в T5.
- `--image` — путь к исходному изображению (для режимов img2img, fill, depth и др.).
- `--mask` — путь к маске (для инпейнтинга).
- `--reference` — путь к референсному изображению (для depth - с этого изображения будет переноситься информация о текстуре и пр.).
- `--height`, `--width` — размеры выходного изображения.
- `--upscale_strength` — степень увеличения (для flux_upscale).
- `--guidance_scale` — сила следования промпту. Для обычной генерации оптимальнейшее значение - 3.5; для fill - 30.
- `--num_images_per_prompt` — количество генерируемых изображений за раз.
- `--num_inference_steps` — количество шагов диффузии (чем больше, тем качественнее, но дольше). оптимально - 50.
- `--controlnet_conditioning_scale`, `--depth_strength`, `--img2img_strength` — специальные параметры для отдельных режимов.
- `--text_t5_scale`, `--text_clip_scale`, `--image_siglip_scale` — веса влияния разных эмбеддингов (T5, CLIP, SigLIP).
- `--seed` — фиксирует случайность для воспроизводимости.
- `--output` — путь для сохранения результата.
- `--device`, `--aux_device` — CUDA-устройства для генерации.
- `--dtype` — тип данных (например, bfloat16).
- `--vl_control` — использовать ли Qwen для отбора лучшего изображения из набора (см. функцию `vl_choose` в utils.py). сохраняет одну выбранную картинку если = True.

## Особенности

- Для некоторых режимов используются дополнительные эмбеддинги и обработка изображений (см. функции `get_prompt_and_image_embeds_scaled`, `get_depth`, `remove_bg`, `prepare_image_for_flux_upscale` в utils.py).
- Для ускорения работы можно использовать режимы с суффиксом `_4bit` (экономия видеопамяти).
- Для отбора лучшего изображения из набора можно использовать визуальный классификатор Qwen (см. параметр `--vl_control`).

## Пример запуска

```bash
python main.py --mode basic --prompt "красивый закат над морем" --output sunset.png
```
